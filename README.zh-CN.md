# 字幕批量重命名

[English](README.md) | **简体中文**

一个零第三方依赖的 Windows Python 图形化工具。它按集数匹配媒体与字幕，把字幕改为对应媒体的主文件名，从而方便 PotPlayer 自动加载外挂字幕。

它还能按「轨道层级」批量提取 MKV 内嵌的字幕 / 弹幕轨道，见下文「批量提取内嵌字幕 / 弹幕」。

## 运行

需要 Python 3.10 或更高版本，并确保安装 Python 时包含 Tkinter。

日常使用时，直接双击 `字幕批量重命名.pyw`（重命名）或 `弹幕批量提取.pyw`（提取）。Windows 会通过 `pythonw.exe` 启动程序，只显示图形界面，不显示命令行窗口。两个功能也可以共用同一个窗口，重命名界面右上角有「弹幕/字幕提取...」按钮。

> **提取功能需要 ffmpeg**。程序会依次查找 PATH、`C:\Windows\System32`、`C:\ffmpeg\bin`。
> 找不到时会弹窗提示，重命名功能不受影响。

如果程序无法启动，可在 PowerShell 中运行下面的命令查看错误信息：

```powershell
python subtitle_renamer.py
python subtitle_extractor.py
```

## 使用步骤

1. 选择同时包含媒体和字幕的文件夹。程序只扫描该文件夹，不递归子目录。
2. 分别选择一个媒体文件和字幕文件作为样例。
3. 在两个完整文件名中，用鼠标拖动框选一段完整的集数数字，再点击“确认所选集数”。
4. 点击“生成预览”，检查每条字幕的旧名称、新名称和状态。
5. 确认没有冲突后，点击“执行重命名”。

程序记录所选数字是文件名中的第几个数字字段。例如在 `Anime.S01E03.1080p.mkv` 中选择 `03`，表示使用第二个数字字段；同批其他媒体也会使用第二个数字字段。集数比较忽略前导零，因此 `03` 可以匹配 `3`。

## 命名规则

- 新字幕名为“媒体主文件名 + 字幕语言标签 + 字幕扩展名”。
- 可保留的常见语言标签包括 `zh`、`zh-CN`、`zh-Hans`、`zh-TW`、`zh-Hant`、`chs`、`cht`、`sc`、`tc`、`eng`、`en`、`jpn`、`ja`。
- 未识别到语言标签时只保留字幕扩展名。
- 同一集可以处理多种语言或格式的字幕，但最终目标名称不能重复。
- 不支持 `OVA`、`SP`、`12.5` 等非整数集数作为匹配字段。

支持的视频格式：`mkv`、`mp4`、`avi`、`mov`、`wmv`、`flv`、`webm`、`m4v`、`ts`。

支持的字幕格式：`ass`、`ssa`、`srt`、`vtt`、`sub`。

## 批量提取内嵌字幕 / 弹幕

同一系列的番剧通常由同一个发布组压制，**轨道顺序是固定的**：第 3 条字幕轨在第 1 集是弹幕，在第 12 集也还是弹幕。所以这里不需要按关键词去猜，直接选「轨道层级」即可整批套用。

### 使用步骤

1. 选择视频所在的文件夹，点击「扫描」。程序只扫描该文件夹，不递归子目录。
2. 扫描完成后，「层级核对」表会列出每个视频的第 1 条、第 2 条……字幕轨实际是什么（例如 `chi·弹幕`）。
3. 在「要提取的轨道层级」里勾选需要的层级，可多选；勾「全部字幕轨道」则一次选中所有层级。
4. 点击「生成预览」，检查状态、轨道、输出文件名。
5. 确认后点击「开始提取」。提取在后台进行，可以随时「取消」。

### 层级核对

轨道顺序固定只是通常情况。若某个视频的层级与同批不一致（顺序不同、编码不同，或者干脆少了这一层），该行会以**琥珀色**标出，底部也会给出提示；生成预览时还会再确认一次。这是防止「第 7 集顺序不同、静默提错轨道」的保险。

### 命名规则

- 默认输出到视频同目录，命名为「视频主文件名 + 轨道标签 + 扩展名」，例如 `EP01.弹幕.ass`。
- 轨道标签优先取轨道标题（`弹幕`、`简日`），没有标题时用语言（`zh-CN`），都没有才用 `s3` 这样的层级号。
- 在「统一命名标签」里填一个名字，则整批都用它，适合只提一条轨道时保持整齐。
- 同一视频里多条轨道的标签撞车时，会自动追加层级号（`EP01.chi.s1.ass`、`EP01.chi.s2.ass`），不会因此卡住整批。

### 输出格式

- 默认**保持原始格式**（流复制 `-c copy`）：无损、最快，弹幕的定位与特效完整保留。
- 扩展名按每条轨道的实际编码决定，因此同一批里 `srt` 轨道输出 `.srt`、`ass` 轨道输出 `.ass`。
- 勾选「统一转 ASS」则全部转成 `.ass`。图形字幕（PGS / VobSub）无法转换，会被标记为冲突并阻止执行。

### 安全行为

- 正式提取前完成整批预检，有冲突时不执行任何操作。
- 目标文件已存在时默认跳过并提示；勾选「覆盖已存在文件」才会覆盖。
- 提取先写入 `.part` 临时文件，成功后才替换目标，因此中断不会留下半截文件。
- 执行途中失败或取消时，会删除本次已产出的文件（**覆盖模式下除外**：此时删除只会让你损失更多，所以保留已产出的文件并明确提示）。

## 安全行为

- 正式改名前会完成整批预检。
- 重复视频集数、目标文件已存在或多个字幕生成同一目标时禁止执行。
- 无法提取集数或没有对应视频的字幕保持不变，并显示在预览中。
- 执行途中发生文件系统错误时，会尽力按相反顺序回滚已经完成的改名。
